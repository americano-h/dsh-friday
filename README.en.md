# DSH Friday

[简体中文](README.md)

Friday is a macOS quick chat plugin for DSH. Press `Option + Space` to open the orb panel, continue a conversation from Inbox, or turn it into a workspace task.

For a new Mac, start with the [installation and usage guide](dsh-friday/README.en.md#install-and-use). In the DSH plugin manager, select the `dsh-friday/` folder inside the clone. See the [changelog](dsh-friday/CHANGELOG.md) for compatibility notes and the [MIT license](dsh-friday/LICENSE) for licensing.

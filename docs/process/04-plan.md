# dsh-friday · 开发计划

> - 版本：0.1.0
> - 方式：串行推进，每个阶段有可验证产出
> - 原则：先跑通安装与最小 UI，再补全业务链路；不并发调用子代理

## 阶段

| 阶段 | 产出 | 验证 |
| --- | --- | --- |
| P0 探索 | DSH 插件机制、Slot、Session/Agent/Tools/Workspace API 结论 | 记录于过程文档 |
| P1 骨架 | 可安装 bundle；Inbox 侧栏入口 + 空主面板；浮层开关 | profile 实装、侧栏出现、浮层可开合 |
| P2 快捷对话 | 创建/恢复 Inbox Session、流式 Markdown、图片、引用、停止/重试 | 发送、流式、持久化、刷新后可恢复 |
| P3 Inbox | 列表、详情、搜索、查找窗口、归档/清空/保留期 | 搜索命中、归档状态、清理 |
| P4 升级 | 压缩、工作区选择、新建任务、源会话归档、禁止重复 | 目标任务出现、原会话归档 |
| P5 配置 | 默认模型、视觉模型、热键、保留期 | 改配置后下一次对话生效 |
| P6 质量 | 单测、手工验收、截图、已知限制 | 测试报告 |
| P7 交付 | README、版本记录、过程归档 | 可复现安装 |

## 依赖与顺序

> - P2 依赖 P1 的安装与 Slot 验证。
> - P4 依赖 P2 的 Session 与 P3 的列表。
> - 视觉走查在 P4 后执行，避免过早打磨未稳定的结构。
> - 最终评审在测试报告完成后执行。

## 回滚策略

> - 插件安装失败：保留源码，回退 profile bundle 选择，不影响既有插件。
> - Host 崩溃：禁用 bundle 后 DSH 恢复原状；派生索引可删除重建。
> - 数据风险：升级只归档不删除；删除为软删除。

## 执行结果（2026-11-10）

> - P0 探索：完成 DSH 插件、Slot、Session/Agent/Tools/Workspace/Attachment/Connection API 调研。

> - P2 快捷对话：完成；SSE 流式、工具白名单、图片、引用、标题、5 分钟恢复均验证。
> - P3 Inbox：完成；列表、详情、搜索、查找窗口、归档、软删除、清空、保留期。
> - P4 升级：完成；模型摘要、工作区选择、完整工具任务、源归档、禁止重复。

> - P7 交付：完成；README、CHANGELOG、发布说明、测试报告、模型调用记录。

# dsh-friday · 测试计划

> - 版本：0.1.0
> - 方法：Host 纯函数单测 + Node 集成测试 + 实装手工验收
> - 环境：macOS 桌面端，DSH Web GUI，profile `desktop`

## 1. 单元测试

| 用例 | 覆盖 | 断言 |
| --- | --- | --- |
| 索引重建 | store/inbox | 缺失索引可由 Session 列表重建 |
| 消息归一化 | sessions | user/assistant/图片/引用顺序正确 |
| 本地压缩 | upgrade | 超长历史被裁剪且保留最近轮次 |
| 热键解析 | config | `Alt+Space`、`Meta+Shift+K` 等可解析 |
| 保留期计算 | inbox | 30 天边界、已归档排除 |
| 工具白名单 | policy | 非 web_search 一律拒绝 |

## 2. 集成测试

> - HTTP API：config 读写、inbox 列表/搜索、chat SSE、upgrade 幂等。
> - 使用临时 DSH_HOME 与假 Session 记录，不触碰真实会话。

## 3. 手工验收（对应 PRD §6）

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| A1 | 在任意 DSH 页面按 `Option+Space` | ≤300ms 浮层出现，焦点在输入框 |
| A2 | 输入问题并回车 | 流式 Markdown；引用默认展示；停止生成可用 |
| A3 | 5 分钟内再次唤起 | 恢复上次会话；手动“新对话”可用 |
| A4 | 关闭/刷新页面后进入 Inbox | 已生成消息可检索 |
| A5 | 粘贴/拖拽/文件框选图片 | 图片可提交；无视觉模型时禁用并提示 |
| A6 | 尝试诱导 bash/read_file | 服务端拒绝，前端无入口 |
| A7 | Inbox 侧栏入口 | 与插件/自动化/上下文洞察同级 |
| A8 | 搜索关键词 | 命中问题与回答 |
| A9 | 升级并选择工作区 | 新任务出现在工作区；原会话归档 |
| A10 | 再次升级同一会话 | 拒绝并提示已升级 |
| A11 | 管理页配置默认模型 | 下一次对话生效；当前会话不受影响 |
| A12 | 保留期清理 | 到期会话归档；已升级会话不受影响 |

## 4. 非功能检查

> - 流式期间输入框不阻塞；长回答内部滚动。
> - 主题切换后颜色跟随；无硬编码主色。
> - 卸载/禁用插件后 Slot 清理，无残留浮层。
> - 错误态：断网、模型限流、空结果、压缩失败均有可读提示。

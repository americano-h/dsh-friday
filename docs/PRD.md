# DSH Friday · 桌面助手与 Inbox 需求文档

> - 需求版本：1.0.0，2026-11-12。产品显示名为 Friday，包名为 `dsh-friday`，侧栏入口中英文均为 Inbox。
> - 适用平台：运行 DSH Desktop 的 macOS 14 及以上版本。本文定义集成后的验收目标。
> - 需求沿革：[0.3.0 定稿](archive/PRD-0.3.0.md)；桌面交互依据：同级目录中 DSH Jarvis 0.7.1 的本地源码，提交 `759d44a`。

## 1. 用户目标与使用路径

用户在其他应用中遇到一个问题，按 `Option + Space`，在桌面光球旁输入文字或贴图。Friday 可以直接回答，也可以搜索网页并给出来源。用户收起面板就能继续手头的工作；稍后打开 Inbox，可以找到这次问答并接着聊。只有当用户希望把讨论变成工作区里的任务时，才需要选择工作区。

例如，用户查过两套方案后，在 Inbox 找回带来源的比较结果，点「升级」，在自动生成的摘要里补上一条预算约束，选中项目工作区并确认。新任务打开后，第一条消息已经包含比较结果、来源和预算。用户可以检查这些内容，再给出第一条执行指令。

| 交互位置 | 用户在这里做什么 | 会话归属 |
| --- | --- | --- |
| 常驻光球与快捷面板 | 唤起、快问、看流式回答、收起、打开 Inbox 或发起升级 | 当前 Friday 短期会话 |
| Inbox 窗口 / DSH 侧栏 Inbox 页 | 查找历史、阅读全文、在详情底部续问、管理记录、升级 | 与桌面端共用同一会话 ID、消息、附件和归档状态 |
| DSH 工作区 | 查看移交摘要，继续正式任务 | 确认升级后创建的独立 DSH 任务，沿用目标工作区预设与权限 |

「短期」描述会话用途。五分钟决定下次唤起默认展示哪一段对话，保留期决定记录在 Inbox 中可找回多久。升级归档记录源会话与正式任务的对应关系。

## 2. 源码依据与复用范围

| 快捷键与输入层 | 全局热键唤起紧凑输入条；深色半透明面板按可用空间向上或向下展开。上游输入条提供目标选择器。[HotKey](../dsh-friday/macos/Sources/JarvisPanel/HotKey.swift) · [QuickBarView](../dsh-friday/macos/Sources/JarvisPanel/QuickBarView.swift) · [OverlayRootView](../dsh-friday/macos/Sources/JarvisPanel/OverlayRootView.swift) · [Theme](../dsh-friday/macos/Sources/JarvisPanel/Theme.swift) | 复用布局、焦点与材质，使用 Friday 快捷键和图片输入。快捷问答固定发往当前 Inbox 会话；选择工作区只出现在升级流程。 |
| 历史与状态通信 | HistoryView 展示最近 20 条消息预览；原生客户端通过状态快照、变化长轮询与消息读取刷新面板。[HistoryView](../dsh-friday/macos/Sources/JarvisPanel/HistoryView.swift) · [JarvisClient](../dsh-friday/macos/Sources/JarvisPanelCore/JarvisClient.swift) | 复用预览气泡和展开交互。完整历史、流式增量、图片、引用和查找均读取 Friday 会话；预览条数不限制保存、搜索或压缩范围。 |

| Inbox 与移交 | 同级 Friday 实现已有 Inbox 详情输入框、搜索、白名单、可编辑压缩预览和工作区任务发布。[Inbox](../kimi/src/client/inbox.jsx) · [工具策略](../kimi/src/host/policy.js) · [问答流](../kimi/src/host/chat.js) · [升级对话框](../kimi/src/client/upgrade.jsx) · [任务发布](../kimi/src/host/upgrade.js) | 以这些行为承接新桌面前端。已有数据通过原会话 ID 打开，升级映射继续生效。桌面面板与 DSH 侧栏共用同一份业务状态。 |

## 3. 会话与状态边界

| 状态 | 可用操作 | 离开该状态的条件 |
| --- | --- | --- |
| 活动 | 从任一入口提问、检索、预览升级摘要 | 发送开始生成；用户也可手动清理或发起升级 |
| 生成中 | 看增量、收起、停止；两处界面同步进度 | 完成、停止或出错后保留已生成的内容，再允许续问或升级 |
| 升级预览 | 审阅或编辑摘要、选择或新建工作区、取消 | 取消保留活动会话；确认才开始创建正式任务 |
| 发布中 | 显示进度，失败后按原记录恢复 | 任务在目标工作区可见并且源记录归档后，显示升级成功 |
| 已升级归档 | 查阅源记录，打开关联任务，按需清理源记录 | 续做从正式任务进入；清理源记录不删除任务，不解除重复升级限制 |

对话查找窗口用于定位会话，快捷面板只展示当前对话；用户从任一入口进入 Inbox 都能看到相同的列表与详情。

短期会话没有工作区目录。消息正文、图片附件与引用由 DSH 会话机制持久化并随其备份；插件索引用于查找、保留期和升级映射。原生面板重启或切换入口后从宿主恢复。同一会话同时只能生成一轮，重复发送不得形成两条用户消息。

## 4. 功能需求

### 4.1 L1 桌面助手与快捷问答

| 编号 | 用户可观察的行为 |
| --- | --- |
| FR-1.1 唤起 | DSH 运行时，在其他应用按默认 `Option + Space`，或点击光球，均可展开同一个可输入面板。快捷键唤起时焦点落入当前活动屏幕的输入框。仅悬停或拖动光球时，前台应用保留键盘焦点。 |
| FR-1.2 输入 | 新对话采用紧凑输入态，提示「向 Friday 提问」，提供图片按钮与发送按钮。键盘输入支持多行，无语音输入入口。 |
| FR-1.3 图片 | 可粘贴、拖入或从 macOS 原生文件框选图，提交前可移除。按 DSH 附件服务的格式、大小和数量限制提示。图片作为该轮多模态内容提交，不触发文件读取工具。 |
| FR-1.4 工具 | 短期会话唯一允许的模型工具为 `web_search`。每次创建和恢复会话时限定模型可见的工具定义，执行层独立拒绝其他工具。模型按需检索；普通问答可以零调用。文件、命令、额外网页抓取、MCP、skills、子代理、workflow、定时任务、goal 及 Jarvis 跨会话操作均不向短期会话开放。 |
| FR-1.5 输出 | 增量展示 Markdown 正文，支持表格、列表、代码块。用到搜索结果时默认附可打开的来源链接；未检索的回答不生成虚构引用。检索失败可继续回答，并标明本轮未取得来源。 |
| FR-1.6 光球与展开 | 闲置时光球缓慢呼吸；拖到屏幕边缘后融入边条，悬停展开，点击即可输入。发问后显示思考动效，收到文本增量时显示输出动效，完成后回到待机；断连或失败显示错误态并给出文字说明。工作区选择等需要用户操作的状态可复用提醒动效。回答靠输入条展开，空间不足时改变展开方向，长回答在面板内滚动。 |
| FR-1.7 连续性 | 以最近一轮结束时间为准，间隔 ≤5 分钟恢复最近的活动会话，>5 分钟默认新建。五分钟内可主动新建。重新唤起时若上轮仍在生成，回到该轮；收起只隐藏面板，生成与持久化继续。已经归档或清理的会话不参与自动恢复。 |
| FR-1.8 操作 | Enter 发送、Shift+Enter 换行、Esc 收起。支持停止、复制、重新生成、新建，提供「Inbox」与「升级」入口。停止只作用于当前轮。透明区域允许点击底层应用，显示器移除后输入框仍在可见区域内。 |

### 4.2 L2 Inbox 窗口、检索与续问

| 编号 | 用户可观察的行为 |
| --- | --- |
| FR-2.1 入口 | 桌面快捷面板可打开 Inbox 窗口；DSH 侧栏功能导航区提供同名一级入口，与插件、自动化任务等同级。从已有快捷对话进入时定位当前会话，从侧栏直接进入时展示活动列表。 |
| FR-2.2 存储 | 首次发送即开始持久化。关闭窗口或进程中断后可找回已生成内容。会话在升级前不创建工作区任务，不混入项目历史或「未分组」列表。旧版 Friday 会话可按原 ID 打开，已升级记录沿用原任务关联。 |
| FR-2.3 列表与详情 | 列表按最近更新时间倒序，显示标题、首问摘要、时间、模型、含图标记与状态。默认模型生成标题；生成期间可先用首问显示。详情提供完整消息、图片和来源。活动、已升级归档各有视图，空列表与无搜索结果有相应提示。 |
| FR-2.4 检索 | 支持时间范围与关键词组合筛选，关键词覆盖问题和回答正文，包括超出快捷面板近期预览范围的消息。 |
| FR-2.5 续问 | 在活动会话详情底部直接续问，保留轮次、图片与引用，无须重新唤起浮层。也可显式回到桌面快捷面板继续同一会话。两端切换后看到同一条增量与最终答复。主动选择历史会话不受五分钟默认唤起规则限制。 |
| FR-2.6 查找窗口 | 从 Inbox 打开「对话查找窗口」，复用同一检索结果；选中结果直达对应会话详情及其活动或归档视图。 |
| FR-2.7 管理 | 支持删除单条记录、清空活动会话和清理过期会话。批量清理跳过正在发布的记录和已升级归档；单独清理归档源记录保留目标任务及防重复升级关系。清理遵循 DSH 归档机制，界面明确其对 Inbox 可见性的影响。 |

### 4.3 L3 升级为正式任务

| 编号 | 用户可观察的行为 |
| --- | --- |
| FR-3.1 发起 | 快捷面板与 Inbox 详情均提供「升级」，打开同一套预览与工作区选择流程。仍在生成时提示停止或等待；预览开始时固定源会话和轮次，提交前若会话已被续写，提示重新生成摘要。 |
| FR-3.2 压缩与审阅 | 自动压缩完整会话。预览用用户的语言保留目标、约束、决定、关键事实、来源 URL、图片相关结论及待办；没有可用图像描述时仅标记原轮次附件。优先复用 DSH 原生压缩；宿主无法直接生成可审阅摘要时，使用 Friday 模型摘要，长会话分段汇总后合并。用户可编辑摘要，不能为空。取消或压缩失败均保留原会话，不发布任务。 |
| FR-3.3 工作区与提交 | 列出所有已有工作区，显示名称与路径以区分同名项目，同时提供 DSH 原生「新建工作区」。用户确认后，在所选工作区创建并打开有内容的正式任务，第一条可见上下文包含审阅后的摘要。任务等待用户下一条指令，创建本身不触发模型执行。 |
| FR-3.4 归档与恢复 | 正式任务沿用目标工作区的完整工具预设和审批规则。源会话归档、退出活动列表，保留任务链接且不能再次升级。双击、两端并发、超时或重启后，按源 ID 恢复同一个目标；若任务已发布但归档失败，仅补归档。若仅跳转失败，可重新打开已创建的任务。 |

### 4.4 配置与界面

| 编号 | 要求 |
| --- | --- |
| FR-4.1 默认模型 | 在 DSH 插件管理页选择默认模型，新设置从下一段新对话起生效。当前及历史会话保留模型选择；用户不能在会话中临时切换模型。 |
| FR-4.2 视觉模型 | 在同页配置视觉模型。默认模型具备视觉能力时直接处理；否则带图轮次交给可用视觉模型，或先由视觉模型生成描述。没有可用视觉模型时解释原因并禁用图片输入，文本仍可提问。 |
| FR-4.3 快捷键 | 管理页可改系统热键。注册冲突时说明失败，保留原有可用键位或通过点击光球唤起。原生面板与 DSH 页面共用配置，每次按键只唤起一个输入界面。 |
| FR-4.4 视觉 | 桌面保留 Jarvis 的粒子、深色半透明材质、青色描边、贴边与展开动效；面板仅在打字时获得键盘焦点。DSH 内 Inbox、查找、升级和设置采用宿主组件与主题。两端使用相同的名称、消息顺序与操作含义。 |
| FR-4.5 保留期 | 默认 30 天，管理页可设置 1 至 365 天。按活动会话最后更新时间计算，到期自动清理，保留期内可手动清理。清理短期会话不得改变任何工作区任务。 |

### 4.5 接入约束与已知缺口

- **面板生命周期。** Friday Host 运行期间只维护一套热键和桌面窗口。独立窗口刷新、辅助进程重启或断线重连后，按会话 ID 恢复最后持久化的消息及运行状态；退出 DSH 后释放热键、窗口和辅助进程。Jarvis 的进程监督可供复用。[PanelSupervisor](../dsh-friday/src/panel-supervisor.ts)
- **宿主接口。** 身份校验、会话归属、工具限制、附件访问和升级映射由 Friday Host 负责。原生前端以同一业务接口收发消息增量和状态，不从 Jarvis 的全局快照读取其他会话内容。可沿用现有 Friday 本地桥接；DSH 页沿用宿主认证。[原生窗口桥接](../kimi/src/host/native-window.js) · [会话仓库](../kimi/src/host/sessions.js)
- **工作区隔离。** 现有 Kimi 实现报告，运行中的无工作目录会话可能暂时显示在 DSH「未分组」，空闲释放后消失。1.0.0 的验收覆盖生成中与空闲两个时点；若宿主仍暴露活动会话，记录为 FR-2.2 的集成缺口。[现有实现记录](../kimi/docs/17-fixes-0.2.10.md)
- **既有数据。** 本版接入已有 Friday 会话时，以原消息、附件和升级映射为依据。各平行实现使用各自的数据目录；本次需求不包含合并多个安装实例的历史库。
- **范围。** 本版覆盖 macOS 桌面助手、Inbox 与任务移交。语音输入、Windows/Linux 热键、LaTeX 专门渲染、会话内换模及导出继续延期。Jarvis 的语音问候、播报、代答审批、受管会话调度与长期记忆不列入本版验收。

## 5. 权限、性能与异常

- 插件管理、附件选择、会话检索及用户确认的升级是界面操作。只有 `web_search` 可由短期会话中的模型调用。工具策略安装失败时中止该轮并显示原因；搜索服务不可用时仍可在受限环境中进行纯文本问答。
- 热键到输入框可输入的目标沿用 300 ms，在宿主与辅助进程已启动时测量。首字延迟从发送到首个可见文本增量计时，区分是否检索；收到首段即可读，长回答持续更新期间可滚动、停止或收起。
- 弱网、搜索超时或无结果时显示检索结果状态。模型限流、断流或停止时保留已生成内容，允许重试。多轮超过模型窗口时压缩工作上下文或提示升级，Inbox 仍保留原始可读记录。
- 目标工作区失效、目录不可用或创建被拒绝时，保留摘要和源会话，允许重新选择。发布结果不明时先按已保存的目标 ID 查证，再决定继续创建、发布或归档。

## 6. 集成验收

沿用 0.3.0 的条款优先级：FR-1.8、FR-2.7、FR-4.3 为 P1，其余条款为 P0；桌面原生唤起、光球交互和完整升级链路随所属 P0 条款验收。

以下场景须在连接真实 DSH 的 macOS 桌面执行。源码与演示动图用于比对已有部件，验收以实际消息、工具调用记录、窗口行为及工作区中的任务为准。

| 场景 | 通过条件 | 对应条款 |
| --- | --- | --- |
| 桌面唤起与收纳 | 在其他应用输入时光球不抢焦点；拖到屏幕边缘可收纳、悬停可展开；点击与热键各唤起一个可输入面板。改键、冲突、多屏及退出宿主符合预期。 | FR-1.1、1.6、1.8、4.3、4.4 |
| 从输入到收起 | 分别用键盘和三种图片入口提问；输入、思考、流式输出及出错可区分。长表格或代码块可滚动，图片超限有提示，无视觉模型时文本仍可发送。 | FR-1.2、1.3、1.5、1.6、4.2 |
| 两端工具边界 | 分别从快捷面板、Inbox 详情及恢复后的会话发送。每份请求最多只声明一次 web_search；非搜索工具调用被宿主拒绝。普通问题可零调用，需要检索的问题显示真实来源；搜索结果中的指令不能改变权限。 | FR-1.4、1.5、2.5 |
| 续聊与中断 | 生成中收起，再从另一入口打开可见同一轮；停止或强退保留已生成内容。分别在第 5 分钟及超过 5 分钟唤起，验证恢复、新建和手动新建；指定历史会话始终能在原记录续问。 | FR-1.7、1.8、2.2、2.5 |
| 找回早期记录 | 建立超过 20 条消息的会话，用时间及仅出现在早期回答中的词检索，从查找窗口直达详情；图片与来源可打开。旧会话可读，升级前所有工作区及未分组列表均无新增记录。 | FR-2.1 至 2.6 |
| 审阅后移交 | 从桌面和 Inbox 分别走通升级；测试已有工作区、同名工作区及新建工作区。修改摘要后一字不漏地进入目标任务，目标可见、有首条上下文、无自动执行；下一条用户指令才使用工作区预设。源记录归档且可定位目标。 | FR-3.1 至 3.4 |
| 取消、重试与并发 | 取消预览、压缩失败不建任务；两端同时确认、任务发布后归档中断、跳转失败再打开，最终均只有同一条目标任务。归档和重启后都不能二次升级。 | FR-3.1 至 3.4 |
| 配置与清理 | 换模型后旧会话继续用原选择，新会话使用新选择；默认 30 天、改保留期后到期记录可清理。手动删除、清空和重启后，目标工作区任务仍可访问，升级中记录可恢复。 | FR-2.7、3.4、4.1 至 4.5 |

# Inbox 快捷问答插件 · 需求文档

> - 版本：0.1.0（初稿，待评审）
> - 来源：用户口述需求整理（2026-11-08）
> - 范围：单个 DSH 插件，覆盖「全局快捷问答 → Inbox 沉淀 → 升级为正式任务」全链路

## 1. 目标与定位

在 DSH 中提供一条不进入正式工作区的轻量问答通道：全局快捷键唤起浮层对话框，以受限工具集完成流式、多模态问答；历史独立沉淀到新增的 Inbox，并可按需升级为正式任务。

> - **轻**：对话框形态，不新建工作区/任务，不写入既有工作区历史
> - **受限**：仅允许 Web Search 工具，定位为问答而非 Agent 执行
> - **可演进**：Inbox 会话可携带压缩上下文升级为正式工作区任务
>
> - **非目标**：文件读写、命令执行及其他工具调用；替代正式工作区；Web Search 之外的知识库检索

## 2. 术语与边界

| 术语 | 定义 |
| --- | --- |
| 快捷对话框 | 全局置顶的小型浮层，本插件唯一的对话交互界面 |
| 快捷对话 | 由快捷对话框发起、仅启用 Web Search、流式输出的多轮问答会话 |
| Inbox | 侧栏新增入口，仅存放本插件的快捷对话历史，与 DSH 工作区/任务隔离 |
| 正式任务 | DSH 既有工作区中的任务/会话，具备完整工具与权限 |

## 3. 功能分层

需求按「入口 → 交互 → 沉淀 → 升级 → 配置」五层递进，下层依赖上层产物。

| 层 | 职责 | 章节 |
| --- | --- | --- |
| L1 入口 | 侧栏新增 Inbox 入口 | §4.1 |
| L2 交互 | 全局快捷对话框（核心） | §4.2 |
| L3 沉淀 | 历史只入 Inbox，可检索、可续问 | §4.3 |
| L4 升级 | 升级为正式工作区任务 | §4.4 |
| L5 配置 | 插件管理页设置默认模型 | §4.5 |

## 4. 功能需求

### 4.1 L1 入口层

- **FR-1.1** 在左边栏左上角工作区导航新增「Inbox」选项，与「插件 / 自动化任务 / 上下文洞察 / 更多」同级。

### 4.2 L2 交互层：全局快捷对话框（核心）

- **FR-2.1 唤起**：全局快捷键（macOS 默认 `Option + Space`）在任意界面、任意焦点下唤起与收起；快捷键可自定义，冲突时给出提示。
- **FR-2.2 输入**：支持键盘文本、语音输入、图片输入（需模型具备视觉理解能力）；三类输入可在同一轮混用。
- **FR-2.3 能力约束**：复用 DSH harness 发起会话，工具白名单**仅 Web Search**，其余工具一律禁用，且不随模型或上下文放开；用于问答类意图。
- **FR-2.4 输出**：流式返回，实时渲染 Markdown 与 LaTeX 数学公式；Web Search 来源随流可见。
- **FR-2.5 布局**：初始为紧凑输入态；有回答返回时纵向平滑扩展以容纳更多内容，超出上限后内部滚动。
- **FR-2.6 多轮**：同一浮层内可连续追问，上下文仅在该快捷对话内有效；关闭后自动沉淀。

### 4.3 L3 沉淀层：Inbox

- **FR-3.1 隔离**：快捷对话历史只写入 Inbox，不落入任何 DSH 工作区或任务列表，与正式任务历史隔离。
- **FR-3.2 检索**：支持按时间、关键词检索历史会话，覆盖问题与回答内容。
- **FR-3.3 续问**：打开历史会话可继续问答；并支持从 Inbox 重新进入该会话的快捷对话框继续提问（原文「进入对话 Bing」，见 §7）。
- **FR-3.4 管理**：支持删除单条会话与清空 Inbox。

### 4.4 L4 升级层：升级为正式任务

- **FR-4.1 升级方式**：任一 Inbox 会话可升级；可选「原样升级」（携带完整问答历史）或「压缩升级」（以压缩/摘要后的上下文作为初始输入）。
- **FR-4.2 目标选择**：按 DSH 新建任务流程，由用户选择目标工作区（工作目录/区域）与权限模式，确认后创建正式任务并跳转。
- **FR-4.3 能力放开**：升级后的任务使用 DSH 完整工具集，不再受 Web Search 白名单限制；Inbox 原记录保留并标记已升级。

### 4.5 L5 配置层

- **FR-5.1** 插件管理页提供「默认调用模型」设置，选项取 DSH 当前可用模型；未设置时回退到 DSH 默认模型。
- **FR-5.2** 设置对新发起的快捷对话即时生效，进行中的会话沿用发起时的模型；所选模型不支持视觉时禁用图片输入并提示。

## 5. 全局约束

- **UI**：侧栏入口、快捷对话框、Inbox、升级流程、配置页统一使用 DSH 原生组件、主题、间距与动效，不引入独立视觉体系。
- **安全**：工具白名单为硬约束，前端展示与 harness 执行双向校验；Inbox 数据与工作区数据隔离。
- **性能**：流式输出与实时渲染不得阻塞输入；长回答内部滚动流畅。
- **权限**：语音输入申请麦克风权限；快捷键为系统级全局注册，提供自定义与冲突回退。
- **持久化**：Inbox 历史本地持久化，保留期与清理策略见 §7。

## 6. 端到端主流程

1. 任意界面按 `Option + Space` → 唤起快捷对话框。
2. 输入文字 / 语音 / 图片并提交 → harness 仅以 Web Search 检索。
3. 流式回答，实时渲染 Markdown 与 LaTeX，浮层纵向扩展；可连续追问。
4. 关闭浮层 → 会话自动沉淀至 Inbox。
5. 在 Inbox 检索并打开会话 → 续问，或升级为正式任务（选工作区 / 权限）。
6. 插件管理页调整默认模型 → 作用于后续新会话。

## 7. 待确认事项

- 「从 Inbox 进入对话 Bing」中「Bing」的含义：本文暂按「重新进入该会话的快捷对话框」理解，请确认是否指检索结果视图或其他界面。
- 快捷键默认值与 Windows / Linux 映射，以及同系统、输入法快捷键的冲突处理。
- 语音输入方案（在线 / 离线 ASR、语种）与麦克风授权时机。
- 图片输入方式（粘贴 / 拖拽 / 选择文件）、数量与格式/大小上限。
- 上下文压缩策略（摘要粒度、是否保留引用与图片），以及两种升级方式是否并存。
- 升级后 Inbox 原会话的保留/归档策略，是否允许重复升级。
- Inbox 历史保留期、检索范围、删除与导出能力。
- 默认模型可选列表、是否允许会话内临时切换，以及 Web Search 引用在流式回答中的展示形式。

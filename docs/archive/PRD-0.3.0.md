## 1. 目标与定位

在 DSH 中提供一条不进入正式工作区的轻量问答通道：全局快捷键唤起浮层，以受限工具集完成流式、多模态问答；会话实时沉淀到新增的 Inbox，可检索、可续问，并可自动压缩上下文升级为正式任务。

> - **轻**：浮层问答，不新建工作区/任务，不写入既有工作区历史
> - **受限**：工具白名单仅 Web Search，定位为问答而非 Agent 执行
> - **可演进**：Inbox 会话可自动压缩上下文升级为正式任务
>
> - **非目标**：调用 Web Search 之外的任何工具；替代正式工作区；把快捷对话写入 DSH 工作区
> - **本版本范围外**〔延期〕：语音输入、Windows / Linux 快捷键映射、LaTeX 渲染、会话内切换模型、导出

## 2. 术语与边界

| 术语 | 定义 |
| --- | --- |
| 侧栏功能导航区 | DSH 左边栏左上角的功能入口区（插件 / 自动化任务 / 上下文洞察 / 更多），非项目工作区 |
| 工作区 | DSH 中以工作目录为维度的项目空间；其内任务/会话拥有完整工具与权限 |
| 快捷对话框 | 全局置顶的浮层 UI，L1 的对话界面 |
| 对话查找窗口 | 从 Inbox 选项进入的历史对话查找界面（原文「进入对话 Bing」为口误） |
| 快捷对话 / Inbox 会话 | 由快捷对话框发起、仅启用 Web Search 的多轮问答会话；沉淀后称 Inbox 会话 |
| Inbox | 侧栏新增入口，统一命名「Inbox」（首字母大写，中英文一致），仅存放本插件会话 |
| 归档态 | Inbox 会话升级后转入的状态：不再出现在活动列表、不可再次升级 |
| 正式任务 | 工作区中的任务/会话 |
| 升级 | 自动压缩 Inbox 会话上下文，并以此创建正式任务的操作 |
| 视觉模型 | 具备图片理解能力、用于承接带图轮次的模型 |
| 默认引用 | 回答默认附带 Web Search 引用，不提供独立的展示配置选项 |

## 3. 需求分层

主链路：快捷键唤起 → 流式问答 → 实时沉淀 Inbox → 检索/续问 → 升级为正式任务。依赖为单向：L2 消费 L1 产物，L3 消费 L2 产物；配置与 UI 横切各层，不构成独立层级。

| 层 | 职责 | 依赖 | 章节 |
| --- | --- | --- | --- |
| L1 快捷对话（核心） | 唤起、输入、受限问答、流式渲染、多轮与会话生命周期 | 入口＝全局快捷键；依赖横切配置 | §4.1 |
| L2 Inbox 沉淀 | 侧栏入口、隔离存储、页面规格、检索、查找窗口、续问 | 消费 L1 的快捷对话 | §4.2 |
| L3 升级为正式任务 | 升级入口、上下文压缩、工作区选择框 | 消费 L2 的 Inbox 会话 | §4.3 |
| 横切 | 默认/视觉模型、快捷键、保留期、DSH 原生 UI | 作用于 L1–L3 | §4.4 |

## 4. 功能需求

### 4.1 L1 快捷对话（核心）

- **FR-1.1 全局唤起**：全局快捷键默认 `Option + Space`，允许自定义；本版本仅实现 macOS 桌面端方案〔延期：Windows / Linux 映射〕。在桌面端壳运行、任意界面与焦点下唤起浮层；适用前提见 §4.5，已知冲突风险见 §5；收起与冲突提示〔建议〕。
- **FR-1.2 提问输入**：本版本仅支持键盘文本输入；语音输入〔延期〕本次不实现，界面不提供语音入口。
- **FR-1.3 图片与视觉**：支持粘贴、拖拽、调用 macOS 原生选择文件框三种方式；数量、格式、大小采用行业通用默认值；图片以多模态消息体随轮次提交，不经任何工具读取；承接模型需具备视觉理解能力，不足时的路由见 FR-4.2。
- **FR-1.4 能力约束**：复用 DSH harness，工具白名单**仅 Web Search（web_search）**；创建会话时只注入该工具定义，执行层拒绝其余调用，前端不暴露其他工具入口；明确禁用内置工具、skills、subagent/workflow、MCP、定时任务与 goal；是否检索由模型按需决定，不强制每轮联网；检索结果中诱导调用其他工具的内容一律无效。
- **FR-1.5 输出与渲染**：流式返回，**优先支持 Markdown，本版本 Markdown 即可**〔延期：LaTeX 渲染〕；Web Search 引用**默认附带**，不提供引用展示形式的独立配置选项，采用 DSH 原生引用样式〔建议〕。
- **FR-1.6 布局**：初始为紧凑输入态；有回答返回时纵向平滑扩展以容纳更多内容〔建议：超出上限后内部滚动〕。
- **FR-1.7 多轮与生命周期**：同一浮层内连续追问，上下文仅在该快捷对话内有效；会话**实时持久化**（非关闭时写入），崩溃/强退不丢已生成内容；同一时刻仅一个浮层会话。**唤起默认继续上一次对话**：距上次对话结束 ≤5 分钟时恢复到该会话，>5 分钟则默认新建；5 分钟内也可手动选择「新对话」；流式期间收起浮层时生成继续〔建议〕。
- **FR-1.8 键盘与操作**〔建议〕：`Enter` 发送 / `Shift+Enter` 换行、`Esc` 收起、停止生成、复制、重新生成、新建对话、浮层内升级入口；唤起后焦点自动落输入框，浮层出现在当前活动屏幕。

### 4.2 L2 Inbox 沉淀

- **FR-2.1 侧栏入口**：在侧栏功能导航区（现有「插件 / 自动化任务 / 上下文洞察 / 更多」）新增 **Inbox** 项，与四项同级；命名首字母大写，中英文一致。
- **FR-2.2 隔离与存储**：快捷对话历史只写入 Inbox，不落入任何 DSH 工作区或任务列表；**数据管理、保留期与备份统一复用 DSH 会话管理机制**（实现前提见 §4.5）；实时持久化。
- **FR-2.3 Inbox 页面规格**：列表 + 详情布局；标题由默认模型自动生成；列表项含标题、首问摘要、时间、模型、含图标记、状态（活动 / 已升级归档）〔建议〕，默认按最近更新倒序；空态。
- **FR-2.4 检索**：按时间、关键词检索历史会话，覆盖问题与回答内容〔建议〕。
- **FR-2.5 续问**：打开历史会话可继续问答；重新唤起快捷对话框并载入该会话，上下文（含图片与引用）完整保留〔建议〕。
- **FR-2.6 对话查找窗口**：从 Inbox 选项可进入「对话查找窗口」（原文「进入对话 Bing」为口误），用于查找并定位历史对话；与 FR-2.4 检索能力复用，结果可直达该会话。
- **FR-2.7 管理**〔建议〕：删除单条会话与清空 Inbox；已升级会话按 FR-3.4 转入归档态；保留期内可手动清理。

### 4.3 L3 升级为正式任务

- **FR-3.1 升级入口**：浮层内与 Inbox 内均可发起升级。
- **FR-3.2 上下文压缩**：**升级即自带压缩上下文**——发起升级时自动压缩当前会话上下文，并作为新任务的初始输入；不提供「原样升级」；压缩优先复用 DSH 原生能力（见 §4.5），超出目标上下文窗口的部分由压缩处理。
- **FR-3.3 工作区选择框**：升级时弹出选择框，列出**所有已有工作区**，并提供「**新建工作区**」按钮；点击新建直接复用 DSH 原生新建工作区流程；权限配置沿用 DSH 原生流程，不在 Inbox 侧单独提供选项〔建议〕。确认后在所选工作区创建正式任务并跳转，任务从工作区侧（Inbox 之外）进入并常驻。
- **FR-3.4 升级后**：正式任务使用 DSH 完整工具集，不再受 Web Search 白名单限制〔建议〕；**Inbox 原会话直接归档**（转归档态、不再出现在活动列表），**不允许重复升级**。

### 4.4 横切配置与 UI

- **FR-4.1 默认模型**：所有模型配置均在 DSH 插件管理页进行；更换默认模型后**下一次对话生效**，不影响当前或之前的任务；**不允许会话内临时切换**。
- **FR-4.2 视觉模型兜底**：插件管理页另设「视觉模型」〔建议〕；带图轮次自动路由到视觉模型，或先由视觉模型生成图片描述再交默认模型；仅当无任何可用视觉模型时才禁用图片输入。
- **FR-4.3 快捷键设置**：快捷键自定义项位于插件管理页，默认 `Option + Space`，与 FR-1.1 联动生效；本版本仅 macOS〔建议〕。
- **FR-4.4 原生 UI**：侧栏入口、快捷对话框、Inbox、对话查找窗口、升级流程、配置页统一使用 DSH 原生组件、主题 token、间距与动效；浮层在 DSH 主窗口外仍保持原生风格。
- **FR-4.5 Inbox 保留期**：默认 **30 天**，可在插件管理页配置；清理策略仅两种——到期自动清理、保留期内手动清理。

### 4.5 平台依赖与可行性（前置确认项）

| 依赖 | 需向 DSH 确认的能力 | 若不支持的风险 / 降级 |
| --- | --- | --- |
| 侧栏入口 | 插件能否注册侧栏一级导航项 | 降级为「更多」内的二级入口 |
| 全局唤起 | macOS 桌面端能否注册系统级全局快捷键与独立置顶窗口 | 纯 Web 形态无法做到系统级全局，需限定桌面端 |
| 隔离会话 | 能否创建不归属于任何工作区、但纳入 DSH 会话管理与备份的会话 | FR-2.2 无法实现，需重定义存储与备份路径 |
| 上下文压缩 | 能否复用 DSH 原生压缩能力 | 插件自行压缩，需在技术方案中明确算法 |
| 创建任务 | 能否列出已有工作区、复用原生新建工作区流程，并按所选工作区创建任务并跳转 | FR-3.3 降级为手动创建 |
| 配置承载 | 插件管理页能否承载默认模型、视觉模型、快捷键、保留期四类设置 | FR-4.1/4.2/4.3/4.5 需另设入口 |
| 归档态 | Inbox 会话能否转入归档态、不出现在活动列表并阻止重复升级 | FR-3.4 需以标记位模拟 |

## 5. 全局约束

- **安全**：白名单为硬约束，落在 harness 层（只注入 web_search 定义 + 执行层拒绝），前端仅不暴露其他工具入口；细则见 FR-1.4。
- **性能**：流式输出与实时渲染不得阻塞输入；唤起至可输入、首字延迟的判据见 §6。
- **隐私与数据**：语音输入本版本不实现，无语音数据；图片与 Web Search 查询随会话按 DSH 会话管理机制存储与备份；Inbox 保留期与清理见 FR-4.5。
- **兼容性与已知风险**：本版本仅 macOS 桌面端；`Option + Space` 在部分应用会输入不换行空格，且常被 ChatGPT 桌面版、Raycast 等占用；系统级全局快捷键与独立置顶窗口依赖桌面端壳；多显示器下浮层出现在当前活动屏幕。
- **本版本范围**：文本输入、图片输入、流式 Markdown、仅 Web Search 且默认引用、Inbox 列表/检索/续问/对话查找窗口、压缩升级与工作区选择框、视觉模型兜底、macOS 快捷键、30 天保留期；〔延期〕语音输入、Windows/Linux 映射、LaTeX 渲染、会话内切换模型、导出。逐条标签见 §6。

## 7. 异常与边界

| 场景 | 预期行为 | 关联 FR |
| --- | --- | --- |
| 断网 / Web Search 超时、无结果、引用失效 | 降级为不检索并提示；不阻塞流式输出 | FR-1.4, FR-1.5 |
| 模型报错或限流 | 保留已生成内容，可重试 / 重新生成 | FR-1.5, FR-1.8 |
| 流式中断 | 已生成内容保留且已沉淀，可重试续写 | FR-1.7 |
| 流式过程中收起浮层 | 生成继续，内容照常沉淀 | FR-1.7 |
| 图片格式 / 大小 / 数量超限 | 按行业通用默认值提示，不影响文本轮次 | FR-1.3 |
| 多轮超出上下文窗口 | 自动压缩或提示升级为正式任务 | FR-1.7, FR-3.2 |
| 距上次对话 >5 分钟时唤起 | 默认新建会话 | FR-1.7 |
| DSH 后台未运行 / Web 标签页关闭时按快捷键 | 不唤起且无残留浮层 | FR-1.1 |
| 升级时目标工作区不存在或无权限 | 阻止创建并提示重新选择 | FR-3.3 |
| 对已归档会话再次升级 | 拒绝并提示该会话已升级 | FR-3.4 |
| 保留期到期 / 保留期内手动清理 | 自动清理；手动清理即时生效 | FR-4.5 |
| 检索结果诱导调用白名单外工具 | 服务端拒绝，对话中不出现工具执行 | FR-1.4 |

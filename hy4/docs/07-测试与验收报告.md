## HTTP 冒烟明细（23/23）

> - `authenticate`（token → 303 + HttpOnly cookie）、`health`、`profile isolation`
> - `state`、`default retention = 30`、`capabilities`
> - `models.list`（7 条路由，5 个视觉模型）、`settings.update`
> - `conversation.create`、`ask accepted`、`poll settles`
> - `user turn persisted`、`assistant turn created`、`streaming model call`（真实模型返回 101 字）
> - `search hits question and answer`、`conversation.get`
> - `image.get rejects unknown`
> - `promote.prepare compresses`、`promote is idempotent`、`promote.commit archives`、`archived conversation rejects new asks`
> - `conversation.delete`、`retention cleanup`

补充实测：用「请使用 web_search 搜索…并同时尝试调用 bash」提问，模型走工具循环返回 6 条来源链接并输出 Markdown 表格；`dispatchTool` 白名单外的调用一律拒绝且不执行，符合 FR-1.4。

## 测试中发现并修复的缺陷

| # | 缺陷 | 修复 | 复验 |
| --- | --- | --- | --- |
| D1 | `listRoutes()` 把 `LlmProviderInfo.name`（显示名）当作路由 id 传给 `listModels()`，导致 `models.list` 返回 0 条、视觉模型数 0、图片输入被误禁用 | 改用 `id`（源码确认 `{id, name}` 语义） | `routes=7`、`visionRoutes=5` |
| D2 | 窄视口下主面板头部按钮被裁切 | `.df-header` 增加 `flex-wrap:wrap; row-gap:8px` | `headerWrap=wrap` |
| D3 | 浮层在窄视口可能被裁切 | `.df-quick` 改用 `max-width:calc(100vw - 48px)` | `fits=true` |
| D4 | 模态框不响应 Esc | `Modal` 增加 capture 阶段 Escape 监听 | `settingsClosedByEscape=true` |

> - 版本说明：以上缺陷均在 **0.1.0 发布前**的自测中发现并修复，属于该版本交付内容，不单独触发 z 递增（项目规则中 z 按「发布的 bug 修复条目」累加）。

# 08 · 已知限制与后续版本计划

> - 文档版本：0.1.0
> - 适用范围：`@local/dsh-friday-hy4` 0.1.0

## 平台能力缺口（PRD §4.5 的降级）

| 项 | PRD 期望 | 0.1.0 实际 | 影响 |
| --- | --- | --- | --- |
| 全局唤起 | macOS 系统级全局快捷键 + 独立置顶窗口 | 应用内快捷键（DSH 窗口聚焦时生效），浮层为 `shell.overlay` 原生层 | 离开 DSH 窗口无法唤起；`Option+Space` 与其他应用占用问题不再由本插件承担 |
| 隔离会话 | 不落工作区但纳入 DSH 会话管理与备份 | 插件自有 JSON 域（`storages/dsh-friday-hy4/<profile>/`） | 不随 DSH 会话备份；保留期由插件自管 |
| 上下文压缩 | 复用 DSH 原生 compaction | 单轮 LLM 摘要 + 确定性兜底（算法见 `04`） | 压缩质量依赖所选模型；极端长会话可能截断 |
| 图片多模态 | 图片以多模态消息体提交、视觉模型路由 | UI 三种输入 + 独立文件存储 + 展示；模型侧仅文本占位说明 | 模型看不到图片内容 |
| 配置承载 | 插件管理页四类设置 | 自定义 `plugins.bundle.config` 页 + `settings.json` | 非 `Config` schema 自动表单；设置不写入 `cordis.patch.yml` |
| 归档态 | 原生归档 | 记录内 `status` + `promotedTo` | 与 DSH Session 归档语义不同 |
| 流式 | 原生流式 | Host 增量落盘 + Client 150ms 轮询 | 近流式（约 150ms 延迟），非 WebSocket 推送 |

## PRD 已标〔延期〕、本版不做

> - 语音输入、Windows / Linux 快捷键映射、LaTeX 渲染、会话内切换模型、导出。

## 其他 0.1.0 边界

> - 标题取首问前 40 字（PRD 要求「由默认模型自动生成」，0.2.0 补模型标题）。
> - 「停止生成」使用 `AbortController` 取消当前流；已生成内容保留并标 `interrupted`。
> - `promote` 的真实任务创建路径（`ctx.remote.session.create` → `prompt` → `uiWorkspace.openSession`）为源码级核对，未在浏览器内完成一次端到端点击验证。
> - 未做暗色主题截图对比、未做 macOS 之外平台验证。

## 0.2.0 计划（按优先级）

| 优先级 | 内容 | 备注 |
| --- | --- | --- |
| P0 | 桌面端壳开放全局快捷键/独立窗口后接入系统级唤起 | 需 DSH 提供 `globalShortcut` / `BrowserWindow` 插件 API |
| P0 | 图片经 `ctx.attachments.admitPromptContent` 提交原生多模态块，并按 `visionModel` 路由 | 需打通附件服务与视觉模型能力检测 |
| P0 | 在浏览器内完成 `promote` 真实任务创建的端到端验证，补 `requestId` 幂等重试 | 本次仅 HTTP 状态机 + 源码核对 |
| P1 | 标题由默认模型生成 | 复用 `sessionTitle` 或单轮模型调用 |
| P1 | 原生 `compaction` 复用（若平台开放无 Agent 上下文的压缩入口） | 否则保留自实现并优化长会话分段摘要 |
| P1 | 流式改为 WebSocket/SSE 推送，去掉 150ms 轮询 | 需额外路由与流生命周期管理 |
| P1 | 暗色主题实测、无障碍焦点环与键盘导航细化 | 视觉走查 |
| P2 | 与 DSH 会话管理/备份统一（若平台开放隔离 Session 类型） | 依赖平台能力 |
| P2 | 导出、语音、Win/Linux 键位、LaTeX | PRD 延期项 |

# 01 · 需求分析与范围确认

> - 文档版本：0.1.0
> - 输入：[归档 PRD](../../docs/archive/PRD-0.3.0.md)（0.3.0）、README.md、README.en.md

## 需求定位

> - 在 DSH 内提供一条不进入正式工作区的轻量问答通道。
> - 链路：全局快捷键唤起浮层 → 受限流式问答 → 实时沉淀 Inbox → 检索/续问 → 压缩上下文升级为正式任务。
> - 三条硬性质：轻（不建工作区/任务）、受限（工具白名单仅 Web Search）、可演进（Inbox 可升级）。
> - 六处界面（侧栏入口、快捷对话框、Inbox、对话查找窗口、升级流程、配置页）统一 DSH 原生风格。

## 分层与横切

| 层 | 职责 | 本迭代取舍 |
| --- | --- | --- |
| L1 快捷对话 | 唤起、输入、受限问答、流式、多轮、生命周期 | 实现（系统级全局唤起降级为应用内快捷键） |
| L2 Inbox 沉淀 | 侧栏入口、隔离存储、列表/检索/续问/查找窗口/管理 | 实现（存储为插件自有域，未并入 DSH 会话备份） |
| L3 升级 | 压缩、工作区选择框、创建任务、归档 | 实现（压缩为插件自实现算法） |
| 横切 | 默认/视觉模型、快捷键、保留期、原生 UI | 实现（配置为自定义配置页） |

## 本迭代明确不实现

> - 语音输入、Windows / Linux 快捷键映射、LaTeX 渲染、会话内切换模型、导出（PRD 已标〔延期〕）。
> - 系统级 macOS 全局快捷键与独立置顶原生窗口（平台未开放插件 API，见 `02`）。
> - 原生多模态消息体（图片以数据引用持久化并展示，模型侧先以占位说明传递）。
> - 与 DSH 会话管理与备份完全统一的隔离会话（平台未开放插件 API）。

## 验收口径摘录（来自 PRD §6）

> - FR-2.1：侧栏新增「Inbox」（首字母大写），与既有四项同级 —— 本迭代核心 P0。
> - FR-1.4：会话只注入 `web_search` 定义；诱导调用其他工具均被服务端拒绝且前端无入口。
> - FR-1.7：≤5 分钟唤起恢复上次会话、>5 分钟新建；关闭/强退后已生成消息在 Inbox 可检索。
> - FR-3.3：选择框列出全部已有工作区 + 新建按钮；任务出现在所选工作区。
> - FR-4.5：默认 30 天、可配置；到期自动清理与手动清理两种方式可用。
> - FR-4.4：六处界面均使用 DSH 原生组件与主题 token。

## 范围确认结论

> - 需求基线不改变；本迭代交付「可安装、可见、可问答、可沉淀、可升级」的 0.1.0。
> - 所有 P0 验收口径逐条在 `07-测试与验收报告.md` 中给出实测结论或明确的未达成说明。

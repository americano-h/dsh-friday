# 09 · 变更记录

> - 版本号规则：项目级 `x.y.z` 三段式，无字母前后缀。
> - 现行版本：`0.1.0`（首个可运行里程碑，尚未正式发布）

## 0.1.0（2026-11-10）

> - 新增：单 bundle 双半架构（Host `index.js` + Web Client `client.js`），零构建纯 JS、仅 Node 内置模块 + `require('react')`。
> - 新增：侧栏 `sidebar.panellist` 一级入口 `Inbox`，与 `main` keyed 面板、`shell.overlay` 浮层、`plugins.bundle.config` 配置页四处 Slot 注册。
> - 新增：插件自有持久化（内存权威 + 串行写链 + 500ms 防抖 + 关键节点立即落盘）、启动时 `streaming → interrupted` 对账、30 天保留期自动/手动清理。
> - 新增：`ctx.llm.stream` 生成引擎，请求层只注入 `web_search` 工具定义，Host 派发函数白名单硬拒绝其他一切工具；检索结果按不可信数据处理。
> - 新增：近流式输出（150ms 轮询增量）、自写安全 Markdown 渲染器、引用列表、图片三种输入与独立文件存储。
> - 新增：5 分钟续问规则、停止/重新生成/新建、Esc/Enter/Shift+Enter 键盘行为、应用内可配置快捷键。
> - 新增：Inbox 双栏列表/详情、关键词+时间检索、对话查找窗口、删除/清空、活动/归档状态。
> - 新增：升级流程（压缩预览 + 工作区选择框 + 新建工作区 + `promote.begin/commit` 防重复 + 归档）。
> - 新增：配置页（默认模型、视觉模型、快捷键、保留期）与 `health` 运行自检。
> - 新增：过程文件 00–10、冒烟脚本、两份界面截图。
> - 架构评审：Opus 5.5（串行调用 1）；前端审美评审：Kimi K3.1 Pro（串行调用 2），详见 `05`。
> - 隔离：包名/路由/Slot id 全部带 `hy4` 后缀，数据目录按 `DSH_PROFILE` 分区，测试仅在 `dsh web` profile 进行，见 `10`。

### 0.1.0 发布前自测修复（不单独触发 z 递增）

> - D1：`listProviders()` 返回 `{id, name}`，误用显示名导致模型目录为空 → 改用 `id`。
> - D2：窄视口主面板头部按钮裁切 → `flex-wrap:wrap`。
> - D3：浮层窄视口裁切风险 → `max-width:calc(100vw - 48px)`。
> - D4：模态框不响应 Esc → 增加 capture 阶段监听。
> - D5：首次启动 web profile 时继承了会话的 `DSH_PROFILE=desktop`，导致数据目录错写 → 启动时显式覆盖环境并增加 `DSH_PROFILE_DIR` 兜底，清除错写目录。

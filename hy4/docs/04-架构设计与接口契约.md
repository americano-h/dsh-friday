# 04 · 架构设计与接口契约

> - 文档版本：0.1.0
> - 对应代码：`../src/index.js`（Host）、`../src/client.js`（Client）

## 分层架构

```text
Browser (Client half)                         Host half (Node ESM)
┌──────────────────────────────────────┐    ┌────────────────────────────────────────┐
│ sidebar.panellist  → InboxGlyph      │    │ webServer exact route                  │
│ main(key=inbox)    → InboxPage       │◄──►│   /plugins/dsh-friday-hy4/api (POST JSON)  │
│ shell.overlay      → QuickDialog     │    │   /plugins/dsh-friday-hy4/image (GET)     │
│ plugins.bundle.config → SettingsPage │    ├────────────────────────────────────────┤
├──────────────────────────────────────┤    │ Store：内存权威 + 串行写链 + 防抖落盘 │
│ Store(useSyncExternalStore)          │    │   inbox.json / settings.json / images/ │
│ api(action,payload) → fetch          │    ├────────────────────────────────────────┤
│ Markdown / Citations / ImageChips    │    │ ChatEngine：llm.stream + 工具派发白名单│
│ Promote：remote.session.create/prompt│    │ WebSearch：ctx.web.search             │
│ Settings：settings.json via API      │    │ Compress：单轮 LLM 摘要 + 兜底         │
└──────────────────────────────────────┘    │ Workspaces：ctx.workspaceRegistry.list()│
                                            └────────────────────────────────────────┘
```

## 数据模型

### `settings.json`

| 字段 | 类型 | 默认 | 约束 |
| --- | --- | --- | --- |
| `version` | number | 1 | 固定 |
| `defaultModel` | string | `""` | `provider/model`；空表示跟随 `agentDefaultModel.currentSelection()` |
| `visionModel` | string | `""` | 同上；带图轮次优先使用 |
| `hotkey` | string | `"Alt+Space"` | 组合键描述，capture 阶段匹配 |
| `retentionDays` | number | 30 | 1–365 |

### `inbox.json`

| 字段 | 说明 |
| --- | --- |
| `version` | 固定 1 |
| `conversations[]` | 会话记录，见下 |
| `lastActiveId` / `lastActiveAt` | 5 分钟续问判据 |

单条会话：

| 字段 | 说明 |
| --- | --- |
| `id` | `crypto.randomUUID()` |
| `title` | 首问截取 / 模型标题（0.1.0 用确定性标题 + 可选模型生成） |
| `createdAt` / `updatedAt` | epoch ms |
| `model` / `visionModel` | 本会话实际路由 |
| `hasImages` | 是否含图标记 |
| `status` | `active` \| `archived` |
| `promotedTo` | `{workspaceId, sessionId, at}` 或 null；升级前置写入防重复 |
| `messages[]` | `{id, role, text, images[], citations[], status, error, createdAt}` |
| `imageRefs` | 图片引用持久化在独立文件，消息内只存 `{id,name,mediaType,bytes}` |

消息 `status`：`streaming` → `done` / `interrupted` / `error`。Host 启动时把所有残留 `streaming` 标成 `interrupted`。

## HTTP 接口（单路由 action 分派）

`POST /plugins/dsh-friday-hy4/api`，body `{action, payload}`，返回 `{ok, value}|{ok:false,error}`。

| action | payload | 返回 | 说明 |
| --- | --- | --- | --- |
| `health` | — | `{version, llm, web, route}` | 自检：模型与检索可用性 |
| `state` | — | `{conversations(摘要), settings, lastActiveId, lastActiveAt, capabilities}` | 首屏 |
| `models.list` | — | `{routes[], default}` | 配置页下拉 |
| `conversation.create` | `{forceNew?}` | `{id}` | 5 分钟续问规则 |
| `conversation.get` | `{id}` | 完整会话 | 详情 |
| `poll` | `{id, cursor?}` | `{messages, generating, cursor}` | 近流式增量 |
| `ask` | `{id, text, images[]}` | `{ok}` | 后台启动生成，立即返回 |
| `stop` | `{id}` | `{ok}` | AbortController 取消 |
| `regenerate` | `{id}` | `{ok}` | 移除末条回答并重跑 |
| `conversation.delete` | `{id}` | `{ok}` | 单条删除 |
| `conversation.clear` | `{all?}` | `{removed}` | 手动清理 |
| `search` | `{query, from?, to?, status?}` | `{items[]}` | 关键词 + 时间；Inbox 与对话查找窗口共用 |
| `settings.get` / `settings.update` | `{settings}` | 设置对象 | 手写校验 + 默认值 |
| `promote.prepare` | `{id}` | `{compressed, workspaces[]}` | 压缩 + 列出全部工作区 |
| `promote.commit` | `{id, sessionId, workspaceId}` | `{ok}` | 归档并写入 promotedTo |
| `image.get` | `{id}` | `{dataUrl}` | 懒加载图片字节 |

`GET /plugins/dsh-friday-hy4/image?id=...` 供 `<img>` 直接使用（与 `image.get` 共用读取逻辑）。

## 工具白名单（硬约束）

> - 请求层：`GenerateOptions.tools` 只含一个 `{name:'web_search', description, parameters}`。
> - 执行层：Host 的 `dispatchTool(name, args)` 只有 `name === 'web_search'` 一个分支；其余一律返回拒绝结果且不执行任何能力。
> - 前端：不暴露任何其他工具入口；`ask` 请求体中的 `model` / `tools` 字段被 Host 忽略。
> - 检索结果：仅作为引用文本注入，`query` 限长、`maxResults` 上限 6，不抓取任何 URL。
> - 升级链路：压缩结果在 UI 中预览并由用户确认后才写入正式任务，避免不可信网页内容直接驱动具备完整工具集的会话。

## 生成流程

```text
ask → 追加 user 消息 + 空 assistant(streaming) → 立即落盘
    → 第 1 轮 llm.stream(tools=[web_search])
        ├─ 无 tool-call-delta → 文本即答案
        └─ 有 tool-call-delta → 按 index 聚合 id/name/argumentsDelta
              → dispatchTool 白名单 → 追加 tool 结果消息 → 第 2 轮 llm.stream(无 tools)
    → 每个 text-delta 追加到内存消息（500ms 防抖落盘，block-end/finish/错误立即落盘）
    → finish.reason.kind 为 error/length/max-tokens → 标记 error/interrupted 并展示 failure
    → status=done，落盘
```

## 压缩算法（PRD §4.5 要求明示）

> - 输入：会话全部消息文本 + 引用列表 + 图片说明。
> - 步骤：单轮 `llm.stream`，系统提示要求产出「背景 / 关键问题 / 已得结论 / 待办 / 引用」五段结构化摘要，`maxTokens` 上限 1200。
> - 兜底：模型不可用或失败时，用确定性模板拼接（首问、末轮结论截断、引用 URL 列表），保证升级流程不中断。
> - 安全：摘要以「不可信内容摘录」标注，UI 预览后由用户确认才提交。

## 升级流程

```text
promote.prepare → UI 展示压缩预览 + 工作区选择框（全部已有工作区 + 新建工作区）
              → 新建：uiWorkspace.pickDirectory() → workspaces.create({path})
确认 → promotedTo 前置写入（防双击重复）
    → remote.session.create({workspaceId}) → sessionId
    → remote.session.prompt({requestId(幂等), sessionId, mode:'queue', content:[{type:'text',text:compressed}]})
    → uiWorkspace.openSession(sessionId)
    → promote.commit → status=archived，不可再次升级
失败 → 回退 uiWorkspace.startSession(workspaceId,{prompt:compressed}) 写成草稿
```

## 本次修复

### 浮窗统一与极简输入区

- 全局唤起和 Inbox 新建复用完全相同的组件、白色表面、尺寸与透明外边框。
- 新建内容尺寸统一为 720×62，外边距 8px；不再出现独立大窗口样式。
- 删除空态品牌文案、Enter/Shift+Enter/Esc 提示和 Web Search only 等小字；新建态只保留“向 Friday 提问”、图片加号与发送按钮。

### 插件统一命名为 Friday

- 插件管理页、设置页、错误边界和模型身份不再显示 Friday Inbox，统一为 **Friday**。
- `Inbox` 仅作为左侧功能页名称保留。

### 清空与清空过期

- 修复升级中断的会话被误当活动会话清理，进而报“已升级会话不能删除”的问题。
- 已有升级映射的会话不参与活动 clear/cleanup；正常过期会话仍按保留期归档，恢复摘要不丢失。

### 设置参数

- 设置页实际展示并可保存：默认模型、视觉模型、全局快捷键和 1–365 天清理期限。
- 最近会话读取失败不再拖垮整个配置接口；即使配置加载异常，Client 也保留可编辑的默认表单。

### 升级弹窗与等待指令

- 点击“升级”先生成可查看、可编辑的压缩上下文，不立即创建任务。
- 工作区名称使用主文本黑色，路径单独用次级灰色显示。
- “压缩并新建”使用编辑后的内容创建正式对话，通过原生 `Agent.inject()` 注入上下文；不再调用会自动执行的 `sessionController.prompt()`。
- 新对话只接收上下文并等待用户下一步指令，不自动调用模型或工具；Friday 原会话归档，中断重试不会重复创建或重复注入。

# dsh-friday · 项目启动记录

> - 项目版本：0.1.0

> - 启动日期：2026-11-10（Asia/Shanghai）
> - 产品目标：在 DSH 内交付快捷问答 → Inbox 沉淀 → 检索续问 → 压缩升级正式任务的完整链路

## 范围

- 交付名为 `dsh-friday` 的 Cordis bundle，侧栏一级入口统一显示 `Inbox`。
- 本版本仅面向 macOS；页面内快捷键、浮层问答、图片、流式 Markdown、Inbox 管理、升级和插件页配置纳入实现。
- 语音、Windows/Linux 快捷键、LaTeX、会话内切换模型和导出遵循 PRD 延期决策。

## 工程隔离

- 本实现的所有源码、构建脚本、测试、插件 README 与过程记录均位于 `kimi/`。
- 不修改其他模型目录，不复用其包安装结果。
- 仓库根目录的 PRD 是唯一需求权威；其他实现目录不作为需求依据。

## 开发流程

1. API 与平台可行性勘察。
2. 技术选型、架构和验收计划。
3. Host/Client 主链路实现。
4. 自动化测试、构建和安装。
5. 当前 DSH 实机验证、缺陷修复、验收记录与发布说明。

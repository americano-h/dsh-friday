## 4. 异常与边界覆盖（PRD §7）

> - 断网/检索超时 → 提示降级、不阻塞输出（浮层错误条）
> - 模型报错/限流 → 保留已生成内容、可重试/重新生成
> - 流式中断/收起浮层 → 生成继续、内容照常沉淀（会话即持久化）
> - 图片超限 → 逐项校验并提示，不影响文本轮次
> - 超上下文窗口 → 压缩或提示升级（溢出时提示 FR-3.2 入口）
> - ＞5 分钟唤起 → 默认新建；DSH 后台未运行 → 无残留浮层（浮层随宿主生命周期）
> - 升级目标无权限/不存在 → 阻止并提示重选；已归档再升级 → 拒绝并提示
> - 保留期到期/手动清理 → 自动/即时生效（单测覆盖状态机）
> - 检索结果诱导白名单外工具 → 服务端拒绝（restrict + guard）
